## 🚀 Featured Project

<div align="center">

### 🔄 AutoSync — LeetCode → GitHub

*Solve on LeetCode. Sync to GitHub. Automatically.* ✨

</div>

A Chrome extension that automatically syncs accepted LeetCode solutions to a GitHub repository using **GitHub OAuth + PKCE**.

| ✨ Feature | 📝 Details |
|---|---|
| 🔐 **Secure Auth** | OAuth-based GitHub authorization with PKCE |
| ⚡ **Auto Detection** | Detects accepted submissions automatically |
| 📦 **Smart Setup** | Repository & branch selection |
| 🔁 **Reliable** | Persistent queue and retry handling |
| 🛡️ **Safe Updates** | SHA-aware GitHub updates |
| 📊 **Insights** | Sync dashboard and activity history |
| 🧪 **Tested** | 39 automated tests passing |

**Stack:** `JavaScript` • `Chrome Extension MV3` • `GitHub API` • `GitHub OAuth` • `Node.js` • `Render`
